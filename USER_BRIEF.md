# User Brief: Smart AI Gateway

**Who is the user?** Your main role is an AI engineer operating a customer-support assistant on a small team. You want each request sent to the cheapest model that can handle it, and you want to spot problems before customers do. During this demo, you also play a fictional bank customer in Chat: send banking questions and judge whether the replies help. Then switch back to the engineer role: use Show details to inspect routing and Health to inspect each model's recent calls and failures. These are two perspectives on the same demo, not separate accounts or login roles.

**Where should you go?** Application: http://149.165.151.225:8080. README: https://github.com/sv642-hub/app-assignment-1#readme

**How should you get started?** (1) In Chat, send three or four banking questions, such as "My card has not arrived." Include one vague message and one that is not about banking. (2) For each reply, click Show details and read the trace: the route (standard or complex), the intent, the reply source and the format check. (3) Open Health and find which model has the most samples (its recent calls, counted separately per model) and whether either one was disabled. (4) Optional: open http://149.165.151.225:8080/docs and send one request through the API.

**What can it do, and what can't it do?** It recognizes ten banking intents, replies from a fictional bank's policy cards, shows how each request was routed, and disables a model whose replies keep failing the format check. Everything is simulated: no real AI models run, intents are matched by keywords, and unmatched requests ask you to describe your banking problem. Each message is handled independently; include the full problem when clarifying. All data resets when the app restarts. Screens for deployments, router metrics and fault injection are not built yet.

**What feedback are we seeking?** Was the app's purpose clear within a minute? Which trace fields helped, and which confused you? What would you need on the Health screen to trust the routing? If answers got worse, what would you check first? Please file each finding as one GitHub issue on our repository (README link above): feature tested, what you expected, what actually happened.
